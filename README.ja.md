# claude-dotpet

Claude Code の入力欄の上にドット絵のペットを出す MOD と、その絵を描き替えるブラウザ用エディタです。

English: [README.md](README.md)

- ペットはセッションの状態で変わります（**待機**・**作業中**・**完了**・**おやすみ**）。
- `/dotpet` で出す・消す・大きさを変えることができます。
- 絵は JSON 1 本にまとまっています。`editor/dotpet_editor.html` をブラウザで開いて塗り、書き出して、コマンド 1 つで反映します。
- 同梱のトカゲは見本です。好きな絵に描き替えて使ってください。

## 状況

- Claude Code のプラグインフック（MOD）の API を使っています。この API は早期アクセスで、版が上がると変わることがあります。
- 開発と動作確認は macOS の Claude Code 2.1.288・2.1.289 で行いました。
- **Windows では確認していません。**

## 入れ方

必要なもの: Claude Code と、反映コマンド用の Node.js 18 以上。

1. このリポジトリを clone します。
2. フォルダをプラグインとして指定して Claude Code を起動します。

   ```
   claude --plugin-dir /path/to/claude-dotpet
   ```

`--plugin-dir` はそのセッションだけ読み込みます。毎回読み込むには、環境変数 `CLAUDE_CODE_PLUGIN_DIRS` に並べたフォルダの中にこのフォルダを置きます。この環境変数は 2.1.288 で動きましたが、`claude --help` には載っていないので、変わる可能性があります。

## コマンド

| コマンド | 動き |
|---|---|
| `/dotpet` | 出す・消すの切り替え |
| `/dotpet on`・`/dotpet off` | 出す・消す（セッションをまたいで保存） |
| `/dotpet big` | 全身。半ブロックの文字で 20 文字 × 5 行（20 × 10 ドット） |
| `/dotpet small` | 全身。オクタントの文字で 10 文字 × 3 行（20 × 12 ドット） |
| `/dotpet image` | 試験中。画像として 12 文字 × 3 行で出す |
| `/dotpet still` | 試験中。動かない画像を 1 枚出す |

補足:

- `small` はオクタントの文字（U+1CD00 以降）を使います。端末のフォントにこの文字が必要です（例: Cascadia Code）。無いと四角い豆腐の表示になります。
- `image` と `still` は kitty の画像表示方式に対応した端末が必要です。`image` は kitty と Ghostty で表示を確認しました。`still` はまだ確認していません。対応していない端末では代わりの文が出るので、`big` か `small` を使ってください。
- 端末以外の画面、入力欄の上の帯の高さが足りないとき、ほかのプラグインが同じ帯に描いているあいだは、ペットを描きません。

## 絵を描き替える

1. `editor/dotpet_editor.html` をブラウザで開きます（開発では Chrome を使いました）。
2. 大きさ・状態・コマを選んで塗ります。
   - `←` `→` でコマを前後に送ります。押し続けると動きを確かめられます。
   - `Shift` ＋ 矢印キーで絵を 1 ドットずつずらします。対象は「この絵だけ」「この状態の絵すべて」「このサイズの絵すべて」から選べます。
3. 「書き出す」を押します。`dotpet_art_<日時>.json` がダウンロードされ、画面にコマンドが出ます。
4. そのコマンドをターミナルで実行します。

   ```
   node "/path/to/claude-dotpet/editor/apply_art.js" ~/Downloads/dotpet_art_<日時>.json
   ```

   コマンドのパスは HTML の置き場所から作るので、どのフォルダからでも実行できます。保存先は `~/Downloads` を前提にしています。ブラウザの保存先が違うときは読み替えてください。
5. 開いているセッションで絵が変わらないときは、`/dotpet` を 2 回打つか、セッションを開き直します。

反映コマンドは、ファイルを検査し、今のファイルを `backup/` に退避してから、`art/dotpet_art.json` と生成物 4 本（`hooks/palette.ts`・`hooks/sit_art.ts`・`hooks/octant_art.ts`・`editor/dotpet_art.js`）を書き、`claude plugin validate` と `claude plugin test` を実行します。検査に落ちたときは退避から戻します。`claude` コマンドが見つからないときは、検査を省いたことを表示して続けます。

| オプション | 動き |
|---|---|
| `--check <ファイル>` | 検査だけ行い、何も書かない |
| `--regen` | `art/dotpet_art.json` から生成物を作り直す |
| `--force` | 下の 2 つの検査で止めずに続ける（内容は表示する） |

終了コード: 0 成功・1 失敗・2 引数の誤り。

### 取り違えを防ぐ検査

- **古い絵を元にした書き出し**: 書き出しには、どの版の絵を元に塗ったかの印が入ります。そのあとで絵が変わっていて、反映するとその変更が失われる場合は止まり、巻き戻る絵と、両方で変えた絵を表示します。今の絵の変更がすべて入っている書き出しは、止めずに反映します。
- **反映していない書き出し**: 書き出しと同じフォルダに、まだ反映していない別の `dotpet_art*.json` があると、名前を表示して止まります。反映したファイルは `apply_ledger.json` に記録します。

`--force` は渡したファイルの絵で上書きします。表示された巻き戻りもそのまま起きます。自動で合わせる機能はありません。

## 絵のデータ

`art/dotpet_art.json` の中身:

- `palette`: 色 9 個。キーは `A S M E P K B C V` で固定です。色の値は変えられますが、キーは増やせません。
- `big`（20 × 10）と `small`（20 × 12）: それぞれ `poses`（絵。1 行が 1 つの文字列、1 文字が 1 ドット、空白は透明）と `order`（各コマがどの絵を出すか）を持ちます。

この版で固定のもの:

- コマ数: 待機 8・作業中 48・完了 8・おやすみ 8。動く速さは `hooks/art.ts` で決めています。
- `small` は、横 2 × 縦 4 ドットの区画ごとに 2 色まで（透明も 1 色に数えます）。端末の 1 文字には文字の色と地の色の 2 つしか指定できないためです。エディタは超えた区画を赤枠で示し、直るまで書き出しません。

## テスト

```
node editor/test_apply_art.js
claude plugin validate .
claude plugin test .
```
